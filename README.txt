프리쇼(PreShow) — 영화 상영 전 대기화면 프로그램
====================================================

■ 실행 방법
  1. 이 폴더(PreShow)를 통째로 USB에 복사합니다.
  2. START.bat 을 더블클릭합니다. 설치는 필요 없습니다.
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
     - runtime 폴더가 비어 있는 '가벼운 버전'을 받았다면, 인터넷이 되는 PC에서
       SETUP_FIRST.bat 을 한 번 실행해 필요한 파일(약 400MB)을 받은 뒤 START.bat 을 실행하세요.
  3. 필요한 것: Windows 10 또는 11 (64비트), Chrome(OTT 재생용), 인터넷.

■ 지원하는 PC 종류
  - 일반 PC (인텔·AMD, x64) : 기본 지원.
  - ARM64 PC (스냅드래곤 등 퀄컴 칩 노트북) : ARM64 전용 파일로 네이티브 실행합니다.
    START.bat 이 PC 종류를 스스로 알아내 맞는 쪽을 실행합니다.
    ARM64 전용 파일이 없으면 x64용으로 실행합니다(윈도우 11에서 동작하지만 더 느립니다).
  - USB 하나로 두 종류 PC를 모두 쓰려면:
      · PreShow_arm64_addon.zip 을 PreShow 폴더가 있는 위치에 풀어 합치거나,
      · 명령 프롬프트에서  SETUP_FIRST.bat all  을 실행해 두 종류를 모두 내려받습니다.
    SETUP_FIRST.bat 을 그냥 실행하면 지금 PC 종류에 맞는 것만 내려받습니다.
  - 32비트 윈도우와 ARM 32비트는 지원하지 않습니다.

■ 처음 한 번만 할 일
  - 오른쪽 위 [설정]에서 TMDB API 키를 입력합니다(영화 정보 자동 조회용, 무료).
    themoviedb.org 가입 → 설정 → API 에서 발급받습니다. 키는 USB의 data 폴더에 저장되어
    다른 PC에서도 그대로 쓰입니다.
  - 키 없이 쓰려면 [영화 정보 직접 입력]으로 제목·줄거리·포스터를 직접 넣으면 됩니다.
  - 상영할 PC의 Chrome에서 OTT(넷플릭스 등)에 미리 로그인해 두세요.

■ 사용 순서
  1. 영화 제목 검색 → 목록에서 선택 (포스터·줄거리·평점·장르 자동 표시)
  2. 예고편: 공식 채널 + 한글 예고편을 자동으로 골라 1080p로 내려받습니다.
     - 맞는 것이 없으면 아래 검색칸에서 다른 사람이 올린 영상을 찾아 직접 고르거나,
       영상 주소 / PC의 영상 파일을 지정할 수 있습니다.
     - [미리보기]로 꼭 한 번 확인하세요. 여러 개를 [사용]하면 번갈아 재생합니다.
  3. OTT 주소, 영화 상영 시각, 출력 화면(프로젝터/TV)을 정합니다.
  4. [리허설]로 약 2분짜리 축약 진행을 미리 봅니다(OTT는 열리지 않음).
  5. [전체화면으로 시작]을 누릅니다.

■ 진행 순서 (상영 시각 기준)
  - 시작 ~ 1분 5초 전 : 영화 정보 화면 50초 ↔ 예고편 반복
  - 1분 5초 전         : 영화 정보 화면으로 복귀
  - 1분 전             : 안내방송 + 자막
  - 10초 전            : 효과음 카운트다운 (10~4초 beep, 3~1초 beep_hi, 0초 beep_go)
  - 상영 시각          : Chrome으로 OTT 주소를 열고 전체화면(F11)

  ※ 남은 시간이 예고편 길이보다 짧으면 예고편을 새로 틀지 않고 정보 화면에 머뭅니다.
     ([설정]에서 "끊고 돌아오기"로 바꿀 수 있습니다.)

■ 상영 화면 조작 키
  - Esc 두 번      : 프리쇼 종료
  - → 또는 ↑      : 상영 시각 1분 늦추기
  - ← 또는 ↓      : 상영 시각 1분 당기기
  - S              : 바로 안내방송 단계로 넘어가기
  - H              : 도움말 표시

■ 휴대전화 리모컨 (선택)
  휴대전화 브라우저로 고정 주소에 접속해 상영 화면을 조종합니다. 같은 와이파이가 아니어도 되고,
  PC와 휴대전화가 각각 인터넷에 연결되어 있으면 됩니다.

  [1] 리모컨 주소 만들기 (처음 한 번, 무료)
    1. github.com 에 가입합니다.
    2. 오른쪽 위 [+] → New repository → 이름을 정하고(예: preshow-remote) Public 으로 만듭니다.
    3. "uploading an existing file"을 눌러 PreShow\remote 폴더 "안의 파일 7개"를 모두 끌어다 놓고 Commit 합니다.
    4. 저장소의 Settings → Pages → Branch 를 main / (root) 로 고르고 Save 합니다.
    5. 1~2분 뒤 주소가 생깁니다:  https://내아이디.github.io/preshow-remote/
       이 주소가 리모컨의 고정 주소입니다. (올린 파일에는 비밀번호가 들어 있지 않습니다)

  [2] PC 설정
    상영 프로그램 [설정] → "휴대전화로 원격 조종 사용"을 켜고 리모컨 비밀번호(8자 이상)를 정합니다.
    오른쪽 위에 "리모컨 대기 중"이 보이면 준비된 것입니다. 설정은 USB에 저장됩니다.

  [3] 휴대전화
    고정 주소로 접속해 같은 비밀번호를 입력합니다. 브라우저 메뉴의 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.

  리모컨으로 할 수 있는 것
    - 현황 보기: 현재 단계, 상영까지 남은 시간, 상영 시각, 재생 중인 예고편, 표시 중인 공지 등
    - 상영 시각 변경: ±1분, ±5분, 또는 시각 직접 지정
    - 화면 전환: 예고편 재생, 영화 정보(줄거리) 화면, 예고편 자동 재생 켜기/끄기, 바로 안내방송
    - 예고편 소리: 음량 조절, 소리 끄기/켜기
    - 공지: 입력한 문구를 상영 화면 위쪽에 띄우기 / 내리기.
      [목록에 추가]로 여러 개를 넣으면 정한 간격마다 돌아가며 표시합니다(최대 10개).
    - 상영 화면 닫기

  주의
    - 비밀번호를 아는 사람은 누구나 조종할 수 있습니다. 길게 정하고 공유하지 마세요.
    - 같은 비밀번호로 여러 PC를 동시에 켜면 모두 반응합니다. 한 번에 한 대만 사용하세요.
    - 공개 중계 서버(무료)를 거칩니다. 내용은 암호화되어 전달되지만, 중계 서버가 멈추면 리모컨도 멈춥니다.
      그럴 때는 PC 키보드로 조작하세요.
    - 회사·학교처럼 외부 접속을 막는 인터넷에서는 연결되지 않을 수 있습니다.

■ 프로그램 업데이트
  - 새 버전이 나오면 세팅 화면 오른쪽 위에 [새 버전 업데이트] 버튼이 나타납니다(인터넷 필요).
    누르면 새 버전을 내려받고 프로그램이 다시 시작되면서 적용됩니다. [설정] → [업데이트 확인]으로도 됩니다.
  - 설정(data 폴더), 실행 파일(runtime 폴더), 안내방송·효과음 파일은 업데이트해도 그대로 유지됩니다.
  - 업데이트는 START.bat 이 다시 켜질 때 적용하므로, 꼭 START.bat 으로 실행하세요.

■ 알아둘 점
  - OTT는 주소를 열고 전체화면으로 만드는 것까지만 자동입니다. 재생 버튼은 OTT에 따라
    직접 눌러야 할 수 있습니다. 가능하면 "바로 재생되는 주소"(시청 페이지 주소)를 넣으세요.
  - OTT 창은 카운트다운 때 미리 준비해 두었다가 상영 시각에 바로 띄우고, 창이 뜨는 즉시 전체화면으로 바꿉니다.
    전체화면이 자동으로 안 되면 F11을 한 번 누르세요.
  - 예고편 다운로드가 갑자기 안 되면 [설정] → [최신 버전으로 업데이트] 또는
    UPDATE_TRAILER_TOOL.bat 을 실행하세요(유튜브가 바뀌면 가끔 필요합니다).
  - 화면이 버벅이면 [설정] → "효과 줄이기"를 켜세요.
  - 배경 조명은 포스터에서 가장 눈에 띄는 색을 따라갑니다. 싫으면 [설정]에서 "포스터 색에 맞춘 조명"을 끄세요.
  - 예고편 재생 중에는 영상 색이 주변으로 번지는 엠비언트 라이트가 켜집니다. [설정]의 "예고편 엠비언트 라이트 끄기"로
    끌 수 있고 세기도 고를 수 있습니다. "효과 줄이기"와는 따로 동작합니다.
  - 리모컨 파일(remote 폴더)이 바뀌면 GitHub 저장소에 다시 올려야 휴대전화에 반영됩니다.

■ 직접 바꿀 수 있는 파일
  - app\assets\audio\           : 안내방송(announcement.wav), 효과음(beep*.wav). 같은 이름으로 교체하면 됩니다.
  - app\assets\subtitles.json   : 안내방송 자막 문구와 시간(초). 안내방송을 바꾸면 여기도 고치세요.
                                   같은 파일의 scenes 항목은 안내방송 중 위쪽 무대에 나오는 장면 8개의 시작 시간입니다.
  - app\assets\channels.json    : '공식'으로 인정할 유튜브 채널 이름 목록.
  - data\                        : 설정 파일(config.json)이 저장됩니다. 지우면 설정이 초기화됩니다.
                                   내려받은 포스터·예고편(data\cache)은 프로그램을 끌 때 자동으로 지워집니다.
